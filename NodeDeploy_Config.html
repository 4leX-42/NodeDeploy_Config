2. Office configuration.xml (Outlook Classic only)

Excluye Word/Excel/PowerPoint/Access/OneNote/Publisher/Teams/OneDrive/Groove/Lync/Bing. Reduce descarga de ~2GB a ~600-800MB (~5-8 min). Compatible Autopilot ESP.
<Configuration ID="NodeDeploy-Outlook-Classic-Only">
  <Add OfficeClientEdition="64" Channel="Current" ForceUpgrade="TRUE"
       AllowCdnFallback="TRUE" OfficeMgmtCOM="TRUE">
    <Product ID="O365ProPlusRetail">
      <Language ID="es-es" />
      <Language ID="en-us" />
      <ExcludeApp ID="Access" />
      <ExcludeApp ID="Excel" />
      <ExcludeApp ID="Groove" />
      <ExcludeApp ID="Lync" />
      <ExcludeApp ID="OneDrive" />
      <ExcludeApp ID="OneNote" />
      <ExcludeApp ID="PowerPoint" />
      <ExcludeApp ID="Publisher" />
      <ExcludeApp ID="Teams" />
      <ExcludeApp ID="Word" />
      <ExcludeApp ID="Bing" />
    </Product>
  </Add>
  <Updates Enabled="TRUE" Channel="Current" />
  <Display Level="None" AcceptEULA="TRUE" />
  <Property Name="FORCEAPPSHUTDOWN" Value="TRUE" />
  <Property Name="AUTOACTIVATE" Value="0" />
  <Property Name="SharedComputerLicensing" Value="0" />
  <Property Name="DeviceBasedLicensing" Value="0" />
  <Logging Level="Standard" Path="%TEMP%\OfficeSetup_NodeDeploy" />
</Configuration>

3. ESET install_config.ini handling

El MSI de ESET Management Agent no auto-detecta el INI. NodeDeploy parsea cada KEY=VALUE y los pasa como properties msiexec inline (~6137 chars cmdline, 9 propiedades). Validado: exit 0 en 45s, service EraAgentSvc Running.
PropertyValorFuncion
P_HOSTNAMEkb4t5os6...ecaserver.eset.comFQDN ESET PROTECT Cloud
P_PORT443Puerto TLS
P_CERT_CONTENT~3000 chars base64 PFXCert peer del agente
P_CERT_AUTH_CONTENT~2500 chars base64 DERCA cert (validar server)
P_CERT_PASSWORD(vacio)PFX sin password
P_CERT_PASSWORD_IS_BASE64yesCodificacion password
P_INSTALL_MODE_EULA_ONLY1Aceptar EULA en silent
P_ENABLE_TELEMETRY1Telemetria habilitada

5. Detection rules Intune (recomendadas)

MSI

Type: MSI
ProductCode: {tomar de cada msi}
ProductVersion: (auto)
PowerShell para extraer ProductCode:
Get-AppLockerFileInformation "x.msi" o Orca.

NSIS / Inno / IS / Burn

Type: Registry (preferido)
Key: HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\<AppName>
Value: DisplayVersion
Detection: greater than or equal to "X.Y.Z"
O alternativa File exists: comprobar exe principal en Program Files.

Office C2R

Type: Registry
Key: HKLM\Software\Microsoft\Office\ClickToRun\Configuration
Value: ProductReleaseIds
Detection: contains "O365ProPlusRetail"

ESET Mgmt Agent

Type: File
Path: %ProgramFiles%\ESET\RemoteAdministrator\Agent\
File: ERAAgent.exe
Detection: exists + version >= 13.1
Adicionalmente service EraAgentSvc Running indica enrolamiento OK.
