## Fixes v4.2 (sesion 2)

### 1. Diagnostico raiz Work Desktop -2147213312

Habilitado `HKLM:\SOFTWARE\InstallShield\29.0\Professional\DoVerboseLogging`. iManage
escribe su propio log en `%TEMP%\workdesktop_v109_4_39_*.log`:

```
### ERROR ###  Work Desktop install did not detect MS Office is installed.
Please address and install again.
```

Causa: iManage Work Desktop 10.9.x detecta Office via Word presence (Outlook solo
no basta). Outlook-only C2R install pasa Outlook check pero falla Office check.

Tambien: `### ERROR ###  Work Desktop install did not detect iManage Agent Services is installed.`
confirma Agent Services prereq hard. Orden: AS → WD.

### 2. configuration.xml por defecto cambiado

Antes: Outlook-only (ExcludeApp Word/Excel/PowerPoint).
Ahora: Word + Excel + PowerPoint + Outlook (core productivity stack que necesita iManage).

Backup viejo: `configuration_OutlookOnly.xml.bak` (NO compatible con iManage Work Desktop).

Descarga ~1.5GB. ~10-15min sobre fibra.

### 3. Detect Microsoft 365 Apps cambiado a WINWORD.EXE

`FilePaths=@("$env:ProgramFiles\Microsoft Office\root\Office16\WINWORD.EXE")`.

Word es mejor proxy de "Office completo" que Outlook (que puede instalarse standalone).

### 4. Smart bootstrap detection ajustado

`if ($hasWord -and -not Outlook -and OutlookClassic.exe disponible)` → bootstrap.
Antes era `$hasBaseline = Excel | Word | PowerPoint`. Ahora solo Word como gate.

### 5. Gate iManage Work Desktop endurecido

```powershell
if ($App.RequiresOffice) {
    # Comprueba OUTLOOK.EXE + WINWORD.EXE explicitos
    # Comprueba iManage Agent Services instalado
    # Si falta cualquiera -> fail con error claro (no -2147213312 silencioso)
}
```

### 6. Office Background (v4.1 base)

Office (Grupo 4) arranca en background al inicio. Grupos 1-3 corren en paralelo
mientras C2R descarga e instala (~10-15min). Antes de Grupo 5 → Wait Office.

Flag `-SequentialOffice` revierte al modo viejo.

## Findings completos sesion 2

### Defender NO bloquea

Anadidas exclusiones (TEMP path + iManage path + processos) no cambiaron exit code.
Defender no es causa de -2147213312.

### Pending-reboot NO bloquea (post-reboot real)

Post-reboot: CBS / WU / PFRO todos limpios. Aun asi -2147213312.
Eliminado como causa raiz (era hipotesis original HANDOFF v1).

### Agent Services standalone vs Work Desktop bundle: NO conflicto

Probado uninstall Agent Services standalone → Work Desktop sigue -2147213312.
Probado reinstall Agent Services → cambia el error en log iManage (pasa AS check,
ahora falla Office check). Confirma que Agent Services es prereq HARD.

### Fake registry keys Word/Excel NO bastan

Inyectados `HKLM:\SOFTWARE\Microsoft\Office\16.0\Word\InstallRoot` con Path.
iManage sigue fallando Office detect. Usa MSI ProductCode query o detect mas
profundo (no simple reg key).

Solucion = Office full C2R instalado real (no hack).

### Interactive launch = mismo exit code que silent

Wrapper aborta ANTES de mostrar UI cuando prereqs fallan. Silent vs no-silent
no cambia comportamiento.
