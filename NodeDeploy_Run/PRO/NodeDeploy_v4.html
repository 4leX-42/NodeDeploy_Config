2. Root cause iManage Work Desktop exit -2147213312 (0x80042000)

El bug real (confirmado v4.2)

iManage Work Desktop 10.9.4.39 es un InstallShield Setup Player V29 con InstallScript que ejecuta pre-checks ANTES de mostrar UI. Si cualquier prereq falla, el script aborta con HRESULT 0x80042000 ("Aborted by user" silencioso). El IS engine setup.log siempre dice ResultCode=0 (porque dialogs aceptados), pero el InstallScript abort retorna -2147213312.

Diagnostico real obtenido habilitando HKLM:\SOFTWARE\InstallShield\29.0\Professional\DoVerboseLogging=1 y leyendo %TEMP%\workdesktop_v109_*.log (log propio de iManage):

### ERROR ###  Work Desktop install did not detect iManage Agent Services
                is installed. Please address and install again.

### ERROR ###  Work Desktop install did not detect MS Office is installed.
                Please address and install again.

Es decir, dos prereqs hard:

  1. iManage Agent Services preinstalado (mismo bundle, ejecutable propio iManageAgentServices.exe).
  2. Microsoft Office con Word presente — Outlook solo NO basta. WD detecta Office via MsiQueryProductState + ClickToRun virtual reg que requiere Word/Excel registrados.

El XML configuration.xml original excluia Word/Excel/PowerPoint (perfil "Outlook only" ~600MB). Con ese perfil, WD aborta silenciosamente. Solucion: XML por defecto ahora incluye Word+Excel+PPT+Outlook (~1.5GB descarga).

Hipotesis descartadas en sesion 1

  • FALSO: Pending-reboot bloquea. Test post-reboot real: signals limpios, mismo -2147213312.
  • FALSO: Defender behavioral monitoring. Anadidas exclusiones path + process: mismo exit code.
  • FALSO: Conflicto Agent Services standalone vs bundle. Uninstall + retry: mismo error.
  • FALSO: Office bg paralelo con iManage. Test post-Office-completo serial: mismo error si falta Word.
  • FALSO: Fake registry keys Word/Excel InstallRoot. WD usa MsiQueryProductState, no simple reg key check.

6. Troubleshooting

iManage Work Desktop exit -2147213312 (CRITICO — v4.2 RESUELTO)

  1. Verifica Office completo (no solo Outlook):
    Test-Path 'C:\Program Files\Microsoft Office\root\Office16\WINWORD.EXE'
    Si False: configuration.xml esta excluyendo Word — usa la version v4.2 default (Word+Excel+PPT+Outlook), NO la backup OutlookOnly.
  2. Verifica iManage Agent Services instalado:
    Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*' | ? DisplayName -eq 'iManage Agent Services'
    Si vacio: lanza solo iManageAgentServices.exe /quiet primero.
  3. Habilita IS verbose logging (revela log iManage propio):
    reg add "HKLM\SOFTWARE\InstallShield\29.0\Professional" /v DoVerboseLogging /t REG_DWORD /d 1 /f
    Logs iManage en %TEMP%\workdesktop_v109_*.log.
  4. Cierra Office + ClickToRun + iManage procs:
    taskkill /F /IM OUTLOOK.EXE /IM WINWORD.EXE /IM EXCEL.EXE /IM POWERPNT.EXE /IM OfficeClickToRun.exe /IM iManageStayExec.exe
  5. Deploy.bat cleanup — mata procesos iManage residuales.
  6. Deploy.bat resume — reintenta.

Office C2R timeout

Default 40 min (2400s). Si tu red es lenta (<2 Mbps): editar Deploy.ps1 Timeout=2400 -> aumenta.

Sin acceso a internet

  • Chrome: usa MSI corporativo offline — sustituye ChromeSetup.exe por el MSI.
  • Office: ODT pre-cacheado en local (configurar SourcePath en configuration.xml).

Bloqueo de AV/EDR (Cortex XDR / ESET)

Cortex XDR esta en Grupo 6 por diseno (post-iManage). Si ESET bloquea:

  • -SkipApps ESET Management Agent primer run.
  • Resto se instala.
  • Snapshot.
  • Segundo run solo ESET.

Wrapper PowerShell para iManage Work Desktop (Win32App individual)

# Install_iManageWorkDesktop.ps1 — wrapper Intune-friendly
$ErrorActionPreference = 'Stop'
$wrapper = Join-Path $PSScriptRoot 'iManageWorkDesktopforWindowsx64.exe'
$tmp     = Join-Path $env:TEMP "imWD_$(Get-Random)"
New-Item -ItemType Directory -Path $tmp -Force | Out-Null
Copy-Item $wrapper "$tmp\w.exe"

# Extract bundled setup.iss
& "$tmp\w.exe" /s /extract_all:"$tmp\ext"
Start-Sleep -Seconds 5
$iss = Get-ChildItem "$tmp\ext\Disk1\setup.iss" -ErrorAction Stop
Copy-Item $iss.FullName "$tmp\setup.iss"

# Run silent install desde dir corto
Push-Location $tmp
$p = Start-Process -FilePath "$tmp\w.exe" `
    -ArgumentList '/s','/f1"setup.iss"','/f2"setup.log"' `
    -Wait -PassThru -NoNewWindow
Pop-Location

if ($p.ExitCode -ne 0) {
    Write-Error "WD install exit $($p.ExitCode). Check %TEMP%\workdesktop_v109_*.log"
    exit $p.ExitCode
}
exit 0

Autopilot ESP

  1. Importar HW hash del equipo a Intune Autopilot.
  2. Asignar a grupo AAD con perfil Autopilot configurado.
  3. Configurar ESP (Enrollment Status Page) con "Block device use until required apps installed".
  4. Anadir los 15 Win32Apps (o el bundle unico) a "Required Apps" del ESP.
  5. Equipo arranca -> OOBE -> Autopilot enrolment -> ESP instala apps -> escritorio listo.
