8. Lecciones aprendidas deploy real 2026-05-26 (session a60b6fe1)

8.1 ESET Endpoint Security — caza del MSI desde EPI

EPI epi_win_live_installer.exe es live downloader puro (NSIS, 16 MB). NO contiene MSI embebido — verificado escaneando firmas CFB (D0 CF 11 E0) en payload, cero hits.

Al lanzar la UI y avanzar al wizard hasta la pestana "Continuar", EPI descarga el MSI real al cache: 
%TEMP%\eset\bts.session\<guid>\.pkg\
  0\agent_x64.msi          (51.8 MB) - ESET Management Agent 13.1.1110.0
  0\install_config.ini
  1\ees_nt64.msi           (64.5 MB) - ESET Endpoint Security 12.1.2057.3
  1\install.ini             (92 B)  -> [Property] INSTALLED_BY_ERA=1 ACTIVATION_DATA=token:<tenant-token>
  1\policy.dat              (0 B)   - placeholder (policy se baja del agent)
  1\offline.lf              (0 B)   - license file placeholder
Los cuatro archivos del subfolder 1\ deben copiarse juntos al destino — el MSI lee install.ini adyacente para self-configure y aplica el token de activacion automaticamente. Sin estos archivos el MSI instala pero queda sin licencia.

Comando final validado (exit 0, 60s): 
msiexec.exe /i ees_nt64.msi /qn /norestart REBOOT=ReallySuppress ^
  INSTALLED_BY_ERA=1 ^
  ACTIVATION_DATA=token:<tenant-token> ^
  /l*v "msi_ees_nt64.log"
Post-install: egui.exe en tray + servicios ekrn/epfwwfp Running. Licencia se activa automatica via consola PROTECT en proximos minutos (no requiere keyfile manual).

8.2 ESET Management Agent — enrollment fingerprint

Trace log C:\ProgramData\ESET\RemoteAdministrator\Agent\EraAgentApplicationData\Logs\trace.log muestra al rato: 
Error: CFingerprintReader::ReadCurrentFingerprint: fingerprint reading failed
       with error=[Response for request of type DeviceFingerprintRequest was not received in time]
Error: AuthenticationModule: DeviceEnrollmentCommand execution failed with:
       HW fingerprint could not be obtained.
Warning: CReplicationModule: TEMPORARILY_UNAVAILABLE
         (session token temporarily unavailable, device is not enrolled yet)
Causa: Agent intenta leer HW fingerprint via WMI antes que el Endpoint AV este instalado y haya registrado el provider. En orden Agent solo da timeout. Resuelto instalando ESET Endpoint Security despues — el agent reintenta enrollment automaticamente (intervalo ~5-10 min).

Verificacion enrollment OK: status.html muestra "Up time" creciente + policies "Applied" + dynamic groups matched. Si tras 15 min persiste error: Restart-Service EraAgentSvc elevated.

8.3 Conflicto AV (Cortex XDR + ESET Endpoint coexistiendo)

SecurityCenter post-install reporta solo Cortex XDR + Windows Defender al principio. ESET tarda 1-2 min en registrarse en WSC. Tras eso quedan 2 AVs con real-time activos simultaneos:
  • ekrn (ESET kernel scanner + minifilter)
  • cyserver (Cortex XDR engine + ELAM driver)
Riesgo: doble escaneo, cuarentenas cruzadas, posible BSOD por hooks WFP/minifilter chocando. Decision politica empresa obligatoria antes de produccion: passive mode ESET via policy PROTECT, o desinstalar Cortex (msiexec /x {CortexProductCode} /qn).

9. iManage Work Desktop — FAIL persistente (exit -2147213312)

9.1 Diagnostico

Exit code: -2147213312 = 0x80042000 (no es codigo MSI estandar, especifico InstallShield setup.exe bootstrap)
Sintoma: Wrapper retorna en ~40s sin generar NI log MSI NI log InstallShield. No hay %TEMP%\iManage_Work_Desktop_*.log. MSI nunca se llega a invocar.
Pre-condiciones del fail: iManage Agent Services + Drive + Drive Native YA instalados previamente. Servicios imUpdateManagerService + iManageStayExec.exe activos. Hipotesis: el bootstrap detecta version previa de subcomponentes y refusa convivir.
Intentos sin exito:
  1. Wrapper /s /SMS /v"/qn REBOOT=ReallySuppress" (engine intento 1+2)
  2. Reboot fisico + retry mismo cmd
  3. Stop service imUpdateManagerService + kill iManageStayExec.exe + retry (script 7_WorkDesktop_Direct.cmd v1)
Todos fallan exactamente igual: 40s, sin logs, exit -2147213312.

10. Post-snapshot rerun checklist

  1. Backup externo OBLIGATORIO antes de revertir: NodeDeploy_Run\ + 1.Node_Preparation\ a USB/share.
  2. Revertir snapshot.
  3. Restaurar backup al Escritorio.
  4. Copiar bundle ESET Endpoint a folder fuente (engine lo detectara recursivo):
    robocopy "C:\Users\user\Desktop\NodeDeploy_Run\PERSIST\ESET_Endpoint" "C:\Users\user\Desktop\1.Node_Preparation\ESET_Endpoint" /E /XO
  5. Aplicar pre-fix iManage Work Desktop (Estrategia A o B de seccion 9.2).
  6. Lanzar 3_Deploy_REAL.cmd.
  7. Si Work Desktop falla → 7_WorkDesktop_Direct.cmd.
  8. Validar con 5_PostValidate.cmd.
  9. Decidir politica AV Cortex/ESET con admin.
